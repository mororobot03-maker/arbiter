# 아비터 (ARBITER) — MVP

사이버펑크 니편내편 텍스트 웹게임. Node.js + Socket.IO.

## 실행

```bash
npm install        # 처음 한 번
npm run dev        # 테스트용: 타이머 짧게, 최소 2명
npm start          # 실제 규칙: 최소 4명, 기본 타이머
```
브라우저에서 http://localhost:3000 을 연다.

### 혼자 테스트하기
- 새 탭을 열고 주소를 직접 입력해서 여러 명으로 들어간다. (탭마다 다른 플레이어)
- ⚠ "탭 복제"는 쓰지 말 것. 복제한 탭은 같은 플레이어로 취급된다.
- 낮에 생존자 전원이 "준비 완료"를 누르면 바로 밤으로 넘어가고, 투표도 전원이 하면 바로 끝난다.

> PC 전용 (최소 폭 1200px).

### 친구랑 같이 하기 (같은 와이파이)
1. 내 PC IP 확인: Windows `ipconfig` → IPv4 주소 (예: 192.168.0.12)
2. 친구는 `http://192.168.0.12:3000` 접속
3. 안 되면 Windows 방화벽에서 Node.js 허용

## 온라인 배포 (Render 무료)
1. GitHub에 이 폴더 내용을 올린다 (`node_modules`는 빼고. `package.json`이 저장소 맨 위에 있어야 함)
2. render.com → New → Blueprint → 저장소 선택 → Apply (render.yaml을 읽어서 설정이 자동으로 채워짐)
3. 발급된 `https://arbiter-xxxx.onrender.com` 주소를 친구들에게 공유

무료 요금제 특징
- 15분 동안 아무도 접속하지 않으면 잠들고, 다음 접속 때 깨어나는 데 약 1분 걸림 (게임 중에는 안 잠듦)
- 서버가 재시작되면 진행 중인 방은 사라짐 (저장 기능 없음)
- 게임 중 새로고침·잠깐 끊김은 같은 브라우저로 다시 들어오면 이어서 진행

## 방 설정 (대기실, 방장만)
심사 기간 5~10일 / 아침 뉴스 5~15초 / 아침 토의 30초~3분(기본 1분) / 지원금 투표 20~60초 / 암시장 30~90초 / 낮 1~5분.
밤은 그날 사건 수에 맞춰 자동: 무슨 일이 일어난 사람당 4.3초 + 마지막 정리 화면 8초.
게임이 끝나면 "로비로 돌아가기"로 같은 방 대기실에 복귀 (설정·방장 유지, 나간 사람은 정리). 다른 사람은 버튼을 누를 때까지 보고서를 계속 볼 수 있음.

## 10차 변경: 회의 투표 주제
아침 뉴스에 오늘의 주제가 발표되고, 토의·투표 때 화면 위에 주제 카드가 크게 뜸 (지원금이면 유리 저금통).
| 주제 | 방식 | 확률 비중 | 규칙 |
|---|---|---|---|
| 지원금 | 누구 | 40 | 최다 득표자가 보조금. 어제 받은 사람 제외, 동률이면 사라짐 |
| 피해 1 | 누구 | 14 (3일차부터) | 생존자 과반 득표 필요, 방어 불가, 유사체력 먼저 깨짐, 사망 가능 |
| 벌금 | 누구 | 14 | 최다 득표자 −₵2,000 → 다음 보조금에 적립 |
| 랜덤 카드 3장 | 누구 | 14 | 최다 득표자에게 랜덤 카드 3장 (판매가 0) |
| 자본 1위 공개 | 찬반 | 12 | 통과 시 크래딧 1위 이름·금액 공개 |
| 부의 균일화 | 찬반 | 6 | 통과 시 생존자 크래딧을 똑같이 나눔 (나머지는 보조금 적립) |
- 같은 주제는 이틀 연속 안 나옴. 찬반은 찬성 > 반대여야 통과 (동률 부결). 누구 투표는 동률이면 무효(동률 결정권 적용)
- 표 배수·블랙리스트·개표 감시·동률 결정권은 모든 주제, 커미션·횡령은 지원금 주제에만
- 숫자는 `server/gameState.js` 의 `RULES.voteTopics` 에서 조정

## 9차 변경
- **유사체력**: 가장 먼저 깨짐 — 피해 1(카드 대신)이든 2 이상(체력 대신)이든 그날 공격을 통째로 막음
- **네온캐스트 특수능력 = 가짜 밤 장면**: 공격/방어/돈/정보 중 고르면 그날 밤 결과에 진짜처럼 섞임 (공개 체력·유사체력과 어긋나지 않는 것만: 카드 −1, BLOCKED, 도둑질, 조사당함)
- **조사당함 장면**: 정보 카드에 당한 사람은 밤 장면에 스캔이 뜸 (누가 했는지는 비밀)
- **기술자 + 방화벽**: 오늘 밤 나에게 오는 정보·공작·디버프(조사·정보 수집·도청·폭로·EMP·사보타주·도둑질·파괴·빼앗기·투표권 무효) 전부 무효
- **위조범**: 장부 조작 삭제 / 역추적 = 나를 캐낸 사람 + 그 사람에 대한 정보 1개 (스핀 닥터도 동일)
- **용병 등 공격 카드를 나에게 놓아도** 공격/방어 선택 → 공격을 고르면 대상 고르기
- **밤 결과 차례로**: 한 사람에게 결과가 여러 개면 같은 자리에서 하나씩 (그만큼 장면이 길어짐)
- **버그**: 위쪽 정보 줄의 체력·유사체력이 밤 장면보다 먼저 바뀌던 문제
- **뉴스는 아침에 한 번만**, 토의·투표 때 화면 위에 보조금 유리 저금통 + 큰 금액. 투표 안내 문구 정리
- **데이터 브로커** 카드 표기 '조사'
- **엔딩 연출**: 어두워짐 → 아비터의 눈 → 심사 종료 → 승리 회사 로고 + 요원 아바타 (클릭하면 넘김)
- **결과 화면**: `승리 [로고] 회사 (아바타들)` / 회사별 자산 막대(요원별 칸 + 아바타) / 일차별 자금 선 그래프(선 끝 아바타)
- **동률 판정**: 1인당 평균 자산 = 살아있는 요원의 자산 합 ÷ 처음 인원 (죽은 사람의 돈 제외)

## 8차 변경
- **참가 회사 비밀**: 위쪽 정보 줄 오른쪽에 회사 5개 항상 표시. ✕ = 정보로 알아낸 불참 회사, ✔ = 내 소속·죽은 사람·폭로된 사람의 회사, ? = 모름 (마우스 = 특수능력)
  - 하급 조사: 후보 3개는 5개 회사 전체에서 + 덤으로 불참 회사 1곳
  - 정보 수집 항목: 크래딧 / 손패 1장 / 오늘 밤 쓴 카드 1장 / **어젯밤 쓴 카드 수·계열** / **불참 회사 1곳**
  - 중급·상급 조사: 덤으로 어젯밤 쓴 카드 수·계열
  - **중복 정보 없음**: 이미 본 손패 카드·불참 회사·어젯밤 기록은 다시 안 나옴
- **사이버네틱 선 아이콘** (`public/icons.js`): 계열·능력·자원/송금/특수·투표·페이즈 전부 SVG 아이콘
- **회사 카드**: 사람에게 끌어다 놓으면 그 자리 옆에 선택지 (나 = 자원/능력, 다른 사람 = 송금/능력). 클릭으로는 안 열림
- **판매/버리기**는 다시 글자로
- **버그 수정**: 밤 결과 "카드 찢어짐" 연출이 전역 .card 스타일과 겹쳐 안 보이던 문제 / 손패 파괴·빼앗기·도둑질도 밤 장면으로 표시
- **예약 실패**: 대상 자리에 빨간 ✕와 이유가 뜸 (카드 한도·손패 한도 등)
- **브로커 = 에스크로**: 오늘 내 송금은 상대도 나에게 송금해야 실행, 아니면 대신 자원
- **매일 무료 랜덤 카드 1장**: 암시장이 열릴 때 지급 (판매가 0)

## 7차 변경
- **회사 비밀 패시브 삭제 → 회사 카드 특수능력**: 회사 카드 = ₵ 자원 / ⇄ 송금 / ★ 특수능력 (무제한, 쓰는 날은 수입 없음, 카드 사용 수 1)
  - 헬리오스 🛡 방어 1 · 블랙아이스 👁 정보 수집 1 · 레드라인 ⚔ 피해 1 · 네온캐스트 📡 가짜 뉴스 1줄 · 오리온 📉 공매도(찍은 사람이 오늘 밤 피해를 입으면 +₵4,000)
  - 공격자는 드러나지 않음 (특수능력도 동일). EMP·정보 수집에 안 잡힘
- **위조범 + 위조 허가증**: 오늘 카드 사용 +2 (허가증 자체가 1장이라 실제 +1). 허가증을 빼면 한도를 넘으면 회수 불가
- **회사 카드 디자인**: 회사 로고 + 회사 색. 카드 창은 아이콘 버튼 3개
- **나에게 쓴 카드·투표**: 내 자리에서 고리가 터지고 아이콘이 크게 솟음. 다른 사람에게 투표하면 🗳 도장
- **암시장**: 경매는 계열 아이콘·색만 (등급 비공개, 낙찰·정찰 시 공개). 랜덤 카드는 ? 하나
- **화면 위 가운데 회사 5종**: 이번 판 참가 회사만 밝게, 마우스를 올리면 특수능력
- **텍스트 정리**: 카드 능력은 아이콘 표기(⚔1, 🛡1, 👁 소속하 …, 자세한 건 마우스), 안내 문구·토스트·방송 대폭 삭제

## 6차 변경
- **손패 앞줄 3장**: 회사 카드 + 인물 카드 2장. 3번째 인물 카드부터 뒷줄
- **랜덤 카드 하루 3장까지** (가격·등급 확률은 그대로)
- **경매 5장 = 계열별 1장씩 고정** (무력·정보·기만·공작·정치). 등급은 1성 40% · 2성 40% · 3성 20%
- **죽으면 소속 공개**: 죽은 사람 자리 위 띠에 소속 로고. TERMINATED 글자 대신 해골 아이콘
- **유령 = 전부 보임**: 산 사람의 소속·크래딧·손패·오늘 놓은 카드·송금·투표가 자리 아래 보라색 상자로, 채팅에 "귓속말 전체" 탭. 경매 카드 앞면도 보임
  - 규칙 패널에 "유령은 산 사람에게 정보를 알려주면 안 됨(음성 포함)" 매너 규칙
- **정보원 = 정보 수집**: 손패 1장 / 오늘 밤 쓴 카드 1장(+대상) / 크래딧 중 무작위 1개. 해커 추적도 같은 능력으로 바뀌고 2개 (장부 조작한 사람은 크래딧이 가려짐)

## 5차 변경
- **카드 사용 수에 회사 카드 포함**: 1~2일차 2장 = 회사 카드 + 인물 카드 1장. 돈을 벌지, 카드를 한 장 더 쓸지 선택
- **아침 토의**(2일차부터): 아침 뉴스 → 토의(기본 60초, 방장 설정) → 투표. 생존자 전원이 "토의 끝"을 누르면 바로 투표
- **정치 브로커**: 투표권 무효 삭제 → 커미션 + 대상 표 2배. 커미션은 개표 장면에서 동전이 갈라져 나감 (받은 본인 화면에선 내 자리로, 다른 사람에겐 화면 밖으로 — 누군지는 비밀)
- **표 배수 중첩**: 선동가 2배 × 브로커 2배 = 4표
- **도청 = 실제 대화 감청**: 도청꾼은 대상의 오늘 귓속말 2줄(상대 이름 ???), 해커는 4줄 + 상대 이름. HUD에 감청 기록 창으로 표시
- **전환 연출**: 개표 → 암시장(어두워진 뒤 초록 네온 "암시장 개장") / 암시장 → 낮(어둠이 위로 걷히며 시안빛)
- 밤 "피해 없음" → "특이사항 없음", 밤 정리 화면 8초로 늘림
- 버그: 결과 화면에서 버튼을 누를 때마다 로고 깜빡임·소리가 다시 나오던 문제 수정

## 4차 규칙 변경
- **송금 개편 (금액 입력 삭제)**: 회사 카드 = 내가 ₵1,500 **또는** 상대가 ₵3,000(2배). 서로 보내면 둘 다 이득, 상대가 안 보내면 나는 0
  - 오리온: 보내는 송금 2.5배 / 로비스트 뇌물: 오늘 내 송금 3배 / 송금 대상이 그날 밤 죽으면 대신 자원 얻기
  - 해커 추적: 송금 상대 + 그 사람에게 송금한 사람들 (장부 조작한 사람은 숨김)
- **하루 카드 사용 수**: 2장, 2일마다 +1, 최대 5장 (손패 왼쪽 위에 ●○ 표시, 5차부터 회사 카드 포함)
- **암시장 가격 상승**: 랜덤 카드 ₵1,000 + 매일 250 / 경매 최저 입찰가 ₵300 + 매일 100
- **개표 장면**(투표 뒤 5.5초): 후보별 득표 막대(숫자만 공개, 누가 누구를 찍었는지는 비밀) → 보조금 동전이 당선자에게 날아감 / 동률이면 흩어져 사라짐
- **낮·밤 조명**: 아침 앰버 / 낮 시안 / 밤 남색 배경빛. 밤이 될 때 어둠이 내려오는 셔터, 아침에 햇빛이 쓸고 지나감
- **손패 두 줄**: 인물 카드 4장을 넘으면 5번째부터 뒷줄(위쪽, 조금 작게)

## 3차 화면 정리 (가독성)
- 크래딧: 오른쪽 아래 지갑 / 왼쪽 위 정보 바 크게 (※ 아래 '송금 2배 삭제'는 4차에서 다시 2배 고정 송금으로 바뀜)
- 투표: 나에게도 투표 가능, 동률이면 아무도 못 받음 (이월 없음)
- 암시장: 입찰 버튼 없이 ▲▼ (100 단위, Shift = 1,000). 누르는 대로 반영돼 마감 때 그대로 입찰
- 손패 카드: 마우스 감지 칸(.fan-slot)은 제자리에 고정, 그림만 떠오름 → 흔들림 없음
- 밤: 사이렌·글리치·조용한 밤 장면 삭제. 무슨 일이 일어난 사람만 한 명씩 (한 사람 4.3초)
  - 공격이 날아옴 → 방어막(막으면 BLOCKED, 뚫리면 깨짐) → 결과: ♥ 깨짐 / ◈ 산산조각 / 카드 찢어짐 / 동전 −₵ / 회복 ✚ / TERMINATED
- HUD 태그: 사람 자리에서 선을 뽑아 짧은 정보 (사람당 3줄, 다음 밤 정산 전까지)
  - 공개: 어젯밤 피해·방어·회복 / 비공개(나만): 조사·정보 수집·도청 결과, 송금, 도둑질, 파괴, 역추적, 개표 감시 등
  - 색: 하늘 = 정보, 빨강 = 나쁜 일, 초록 = 좋은 일, 노랑 = 돈. 자리에 마우스를 올리면 그 사람 태그만 강조
- 글자 알림 최소화: 서버 알림 토스트는 사망만 (나머지는 태그·수첩), 페이즈 배너·안내 띠 짧게, 아침 뉴스 상자는 뉴스만
- 개발용: `DEV_HAND=thug,bodyguard,dataBroker` 로 서버를 켜면 모두 그 손패로 시작

## 연출
- **아비터의 눈**: 타이머 다이얼 안의 홍채 고리. 남은 시간에 따라 숨 쉬는 속도가 빨라지고(여유 4초 → 절반 2초 → 막판 0.8초), 마우스를 따라보며, 밤에는 사건 대상 쪽을 바라봄. 4~9초마다 깜빡이고, 방송(페이즈·투표 배너)이 나올 때 떨림
- **손패 카드**: 마우스 위치에 따라 3D로 기울고 홀로그램 광택이 따라옴. 3단계 카드는 늘 무지갯빛이 흐름
- **예약 확정 도장**: 카드·송금을 예약하면 대상 자리에 "LOCKED" 도장이 계열 색으로 찍힘
- **복호화 글자**: 밤 장면 설명과 아침 "어젯밤 내 정보 결과"가 뒤섞인 기호에서 풀리듯 나타남
- **크래딧 카운트**: 돈이 바뀌면 숫자가 굴러가며 바뀜
- **피격**: 내가 맞거나 죽는 장면에서 화면 테두리가 붉게 번쩍이고 색이 번짐
- 시스템의 "동작 줄이기" 설정을 켜면 움직이는 연출이 꺼짐

## 구현 범위
방/로비 → 소속 배분 → 페이즈 타이머 → 채팅(공개·귓속말·유령) → 회사 카드(자원/송금)
→ 지원금 투표 → 카드 구매 턴(경매·랜덤 구매·판매·손패 한도) → 인물 카드 5계열 26종 전부 → 승리 판정 → 결과 타임라인

하루 흐름: 아침(뉴스) → 투표(2일차부터) → 암시장(구매 턴) → 낮 → 밤

무력 계열: 깡패·경호원·응급요원(1단계) / 용병·의무병(2단계, 능력 선택) / 사이보그 용병(3단계)
정보 계열: 데이터 브로커·정보원·도청꾼(1단계) / 해커(2단계) / 고스트 넷러너(3단계)
- 조사 등급: 하급 "3개 중 하나" / 중급 "70% 확률로 X"(실제로 70%만 진짜) / 상급 확정
- 블랙아이스: 조사 등급 +1, 상급이 되면 손패까지 열람
- 폭로(3일차부터): 다음 아침 뉴스로 소속 공개, 이후 원탁에 ⚠ 표시
기만 계열 (전부 나에게 사용): 홍보 담당·브로커·로비스트(1단계) / 위조범(2단계) / 스핀 닥터(3단계)
- 위장: 홍보 담당은 하급 조사까지, 스핀 닥터는 상급까지 가짜 결과
- 위조 신분증: 고른 소속으로 보이게 함 (하급·중급만, 상급엔 뚫림). 위장보다 우선
- 장부 조작: 오늘 밤 추적에 "송금 안 함"으로 보이고, 다음 날 아침 순위 발표에서 빠짐
- 역추적: 오늘 밤 나를 캐낸 사람과 방법(조사/추적/도청/폭로)
- 익명 송금: 받는 사람에게 "익명의 누군가"로 표시 (추적에는 걸림)
- 뇌물: 오늘 송금 한도 +2,000. **송금보다 먼저 예약**해야 하고, 회수하면 한도를 넘는 송금 예약은 자동 취소
공작 계열: 기술자·좀도둑(1단계) / 공작원(2단계) / 금고털이(3단계)
- 사보타주: 대상의 다음 날 회사 카드 정지
- 도둑질 10/20/30%: 대상의 쓸 수 있는 크래딧 기준, 훔친 돈은 다음 아침부터 사용
- 도둑질·손패 파괴·빼앗기는 대상에게 방어가 1이라도 있으면 막힘 (당한 사람에게만 알림, 범인은 비공개)
- 빼앗은 카드는 판매가 0
- EMP(밤 1단계): 대상이 오늘 밤 쓴 인물 카드 1장을 무작위로 무효. EMP끼리는 무작위 순서로 먼저 터진 쪽이 이김

정치 계열 (효과는 전부 다음 날 아침 투표에): 선동가·블랙리스트 작성자·개표 감시원(1단계) / 정치 브로커·횡령 담당관(2단계) / 아비터 로비스트(3단계)
- 횡령: 투표 시작 전에 빼돌림, 전원에게 "지원금이 줄었습니다"만 공지
- 커미션: 내가 찍은 사람이 당선되면 (횡령 후) 지원금의 30%를 당선자 몫에서 가져감
- 표 배수가 여러 개 겹치면 가장 큰 값만 적용
- 동률 결정권: 동률일 때 로비스트가 찍은 사람이 동률 후보 중에 있으면 그 사람이 당선
- 블랙리스트에 오른 사람은 투표 후 "무효 처리" 통보를 받음

네온캐스트 뉴스 조작: 회사 카드 창 아래 "방송망 침투"에 문장을 써서 예약 → 밤에 확정(횟수 차감) → 다음 아침 뉴스 사이 무작위 위치에 섞임

- 경매·랜덤 모두 5개 계열이 각 20%로 등장 (규칙서대로).

## 조작
- **카드 사용: 손패(왼쪽 아래 부채꼴)의 카드를 잡아서 대상 자리에 끌어다 놓기**
  - 끄는 동안 놓을 수 있는 자리만 빛나고, 마우스가 올라간 자리는 금색으로 강조
  - 나에게 쓰는 카드는 아래 "나" 반원에 놓기
  - 능력이 여러 개면 놓은 뒤 "그 대상에게 쓸 수 있는 능력"만 선택창에 뜸 (레드라인은 관통 체크도 여기서)
  - 엉뚱한 곳에 놓으면 손패로 돌아옴
  - (보조) 카드 클릭 → 대상 클릭 방식도 그대로 동작
- 엎어둔 카드: 손패 쪽으로 끌어오거나 클릭하면 회수
- 맨 왼쪽 금색 카드 = 회사 카드: 사람에게 끌어다 놓으면 송금(금액만 입력), 나에게 놓으면 자원 얻기. 클릭하면 창이 열림 (네온캐스트는 뉴스 조작도 여기서)
- **추리 태그: 아바타 우클릭 → 회사 색 고르기.** 테두리 색 + "OO?" 표시, 나만 보이고 새로고침해도 유지 (이 브라우저에 저장)
- 귓속말: 귓속말 탭 위 이름 버튼으로 받는 사람 선택 (금색 = 지금 받는 사람, 전송 버튼에도 이름 표시). 아바타 클릭도 가능
- 왼쪽 위 정보 바 클릭 = 정보 수첩, Esc = 선택 취소
- 아침 뉴스는 아침에만 자동으로 펼쳐지고, 투표·낮에는 위쪽 "📡 오늘 뉴스" 버튼으로 다시 열기
- 암시장: 카드 아래 칸에 입찰액 → 입찰 ("입찰 취소"로 철회), 랜덤 카드는 두 번 눌러 구매 (6초 안에)

## 2차 테스트 후 규칙 변경
- **참가 기업 수 = 인원에 맞춤**: 4~5명 3곳 / 6~8명 4곳 / 9명 이상 5곳. 5개 중 무작위로 뽑고, 기업마다 최소 1명. 시작 방송으로 참가 기업을 공개.
  - 하급 조사는 참가 기업이 4곳 이하면 "2개 중 하나", 5곳이면 "3개 중 하나". 위장·위조·추리 태그도 참가 기업 안에서만.
- **지원금 연속 수령 금지**: 어제 보조금을 받은 사람은 오늘 투표에서 받을 수 없음 (그 사람에게 간 표는 무효, 클릭해도 투표 안 됨).
- **송금 2배 삭제**: 보낸 금액 그대로 도착. 송금 한도는 1일차 2,000 + 매일 250.

## 피해 규칙 개편
- 같은 사람에게 온 공격 합 − 방어 = **남은 피해** (관통은 방어 무시, 계산은 전과 같음)
  - 남은 피해 1 → 손패 1장 무작위 파괴. 손패가 없으면 ₵1,000 손실 (가진 만큼만)
  - 남은 피해 2 이상 → 체력 1 감소. **하룻밤에 잃는 건 체력 1 또는 카드 1**
  - 사이보그 용병의 **압도**가 섞인 피해 2+ → 체력 1 + 카드 1
- 결과 공개: 밤 연출에는 "체력 / 유사체력 / 카드 1장 / 크래딧"만, 깨진 카드 이름은 당사자에게만
- 공작 계열 **손패 파괴는 방어 무시** (도둑질·빼앗기는 여전히 방어에 막힘)
- 새 카드
  - **장갑 시술사**(무력 ★★): 유사체력 +1 (체력이 깎일 때 대신 소모, 쓸 때까지 유지, 최대 1, 모두에게 ◈로 보임) / 방어 1
  - **암시장 정찰꾼**(정보 ★): 다음 날 암시장 경매 카드 5장의 앞면(이름)이 나에게만 보임
- 시작 체력은 3 그대로 (테스트용: `START_HP=2`로 서버를 켜면 2로 바꿔볼 수 있음)

- 시작 손패: 회사 시작 카드 + 랜덤 1단계 1장 (헬리오스=기술자, 블랙아이스=데이터 브로커, 레드라인=깡패, 네온캐스트=홍보 담당, 오리온=로비스트).
- 패시브: 헬리오스(+20%), 블랙아이스(조사 +1), 레드라인(관통 3회), 네온캐스트(뉴스 조작 2회), 오리온(송금 한도 +50%) 모두 작동.

## 임시 규칙 결정 (규칙서 미기재)
| 항목 | 결정 |
|---|---|
| 응급요원 | 남에게도 사용 가능, 최대 체력 3 |
| 여러 공격 | 합산 후 방어를 뺌. 관통 공격은 방어 무시 |
| 레드라인 관통 | 공격 예약 시 체크박스로 선택 |
| 밤에 죽은 사람의 회사 카드 | 취소 (송금액 반환) |
| 사망한 사람에게 송금 | 보낸 사람에게 반환 |
| 전원 동시 사망 | 승자 없음 |
| 마지막 날 평균 자산 | (팀원 전원 자산 합) ÷ 원래 팀원 수 |
| 손패 한도 초과 | 낮에 정리 창이 뜨고, 정리 전까지 카드 예약 불가 (채팅은 가능) |
| 추적 | 대상이 낮에 예약한 송금 기준 (밤에 죽어 취소돼도 "송금했다"로 나옴) |
| 도청 | 오늘 아침~낮 동안 대상이 보내거나 받은 귓속말 상대 전부 |
| 역추적 범위 | 조사뿐 아니라 추적·도청·폭로까지 알려줌 |
| 위장 가짜 결과 | 하급 목록에 진짜 소속은 넣지 않음 |
| 방어 vs 도둑질 | 방어 1이라도 있으면 도둑질·파괴·빼앗기 전부 막힘 (공격 방어와 별개로 소모되지 않음) |
| 뉴스 조작 방식 | 기존 줄을 바꾸는 게 아니라 가짜 1줄을 끼워 넣음 |
| 경매 낙찰 공개 | 1~5번 "팔림 n / 유찰"만 공개, 낙찰자는 비공개 |
